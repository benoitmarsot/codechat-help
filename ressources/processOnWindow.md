# Modify the docs on Windows

1. Open the Git GUI program and pull.
   This refreshes the local disk source so it is synced with the files on GitHub.

2. Start your MkDocs server by clicking the icon on your desktop.
   This lets you see your changes in real time; the server displays the help exactly as it would appear on the published website.

3. Open Notepad++.
   - The project should already be loaded; if not, load it by opening the directory.
   - This is the editor used to edit your markdown (`.md`) files. Use the installed plugin to preview the changes you make.
     - _Click the plugin icon twice if the preview does not refresh._
   - Save the files.

4. Review your changes by going to:
   - http://127.0.0.1:8000/help/

5. Use the Git GUI program to push your changes to the server.
   - You should see the changes in the right panel.
   - Enter a message describing your changes.
   - Click `commit`.
   - Click `push`.
